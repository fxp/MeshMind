连接本机设备

在 Mac 程序中完成接入

  1. 下载上方的 MeshMind Connect 并打开。
  2. 在左侧生成入网文件，然后在程序中点「导入 enrollment.json」。
  3. 添加 ADB、ESP32 串口或 Home Assistant 设备，点「开始连接」。

一台 Mac 只需创建一个网关，可继续添加多台设备。已有命令行网关正在运行时，请先停止它，再迁移到 Mac 程序，避免设备重复。

拓竹 X1C／命令行接入

当前 X1C 仍使用仓库中的命令行网关。在 saas 目录执行：

npm run gateway -- --config gateway.x1c.json --enroll /path/to/enrollment.json
